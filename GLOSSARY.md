# Siphon Glossary

## Following creators

**Followed creator**  
A creator the user has chosen to track for new uploads.

**Upload**  
A publication identified by its platform and the ID assigned by that platform.

**Pending upload**  
An upload discovered while refreshing a followed creator that has yet to be downloaded or marked as ignored.

**Refresh checkpoint**  
The boundary through which a creator's uploads have been checked. For a new follow, the boundary starts at the time the creator was followed.

## Downloads

**Direct download**  
A download started from a user-supplied media URL, regardless of whether the creator is followed.

**Download preset**  
A named set of arguments that can be reused across downloads.

**Default preset**  
The download preset used when the user does not specify one. It starts as the built-in preset and can be changed by the user.
